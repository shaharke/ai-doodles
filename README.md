# ai-doodles

Personal AI plugins marketplace for Claude Code.

## Quick Start

```
/plugin marketplace add shaharke/ai-doodles
```

Then install any plugin:

```
/plugin install gitops
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [gitops](plugins/gitops) | Git workflow automation — conventional commits, smart staging, and more |
